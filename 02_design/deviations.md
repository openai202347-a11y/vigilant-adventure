# Analysis deviations and supplemental checks

1. The frozen plan proposed 2,000 stratified PSU bootstrap replicates for AUC if feasible. An initial run did not implement them and reported no AUC CI. A later supplementary run implemented 2,000 analyst-generated replicates (seed 20261031; survey::as.svrepdesign type bootstrap). It yielded AUC 0.7298, SE 0.02235 and a t-based CI 0.6822–0.7774 with 15 replicate-design degrees of freedom. These are not official NHANES replicate weights. CDC recommends Taylor linearisation; assess the assumptions and method independently before publication.
2. Original primary confidence intervals use Taylor-linearised standard errors and normal approximation, with bounds clipped to [0,1], as initially reported. Additional logit intervals using survey design degrees of freedom were calculated after results; they are sensitivity analyses, not silent replacements of the original method. Sensitivity logit CI is 84.5%–97.3%, versus 88.0%–98.7% using the initial normal approximation. Small event counts and small degrees of freedom need review.
3. Pregnancy information is unavailable in the public demographic field for women aged 45–74; they were not asserted to be non-pregnant.
4. Independent Python reconstruction checked the eligible count, case count, and weighted sensitivity, specificity and positive predictive value against R. A later separately written Python implementation also reproduced Taylor-linearised standard errors for five proportions; it did not validate the bootstrap and was performed within the same project rather than by an independent reviewer.
5. Windows text-encoding labels in outputs were corrected and analysis rerun; calculations were unchanged.
6. Automated reference check confirmed two journal DOIs; five government web references require the separate manual web check. Independent statistical review and complete reporting-guideline assessment remain outstanding.

7. Post hoc exploratory check (2026-10-31): a separately coded weighted AUC influence linearization, using the same public stratum/PSU design, gave AUC 0.729804 and SE 0.021571; the 2,000-replicate bootstrap SE was 0.022353. The influence expression was numerically checked for one case and one noncase. This is an internal sensitivity check, does not establish the validity of the bootstrap interval, and requires independent statistical review.

8. Post hoc descriptive selection comparison (2026-10-31): among 5,340 respondents aged 25–74 reporting no diagnosed diabetes, 3,794 were included and 1,546 excluded after the remaining criteria. Unweighted ages 25–44 were 36.95% among included and 47.74% among excluded; average ages were 51.28 and 47.49 years, respectively. This post hoc, unweighted comparison describes the interview respondent group only. Exclusions include pregnancy-status criteria and missing or ineligible values; it does not measure direction or magnitude of bias or national representativeness. No inferential test or adjustment was prespecified.

9. Post hoc descriptive outcome table (2026-10-31): survey-weighted characteristics within HbA1c outcome groups were calculated without hypothesis testing or model changes. Outcome-positive n=93 and outcome-negative n=3,701; some cells are small and the full NCHS reliability assessment remains outstanding. Main sensitivity/specificity and unweighted cross-tabulation were checked against the generated table.

10. Post hoc AUC internal cross-check (2026-11-01): R survey::svytotal on the AUC influence contribution reproduces the Python public-strata/PSU Taylor-linearized standard error (0.02157132, design df 15). Both methods use the same influence formula and data; agreement checks computational implementation only, does not establish correct application to NHANES, and does not validate bootstrap or replace independent expert review.

11. Internal review correction (2026-11-01): The frozen plan specified design-based 95% intervals and Taylor linearization but did not specify a normal critical value. The manuscript previously described the normal approximation as prespecified; that claim has been corrected to initially reported. Normal-based original results remain unchanged. The design-df logit and t-Wald comparisons are post hoc and require independent evaluation; this correction does not amend the frozen plan.
